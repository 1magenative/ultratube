Что умеет UltraTube

Реклама исчезает

Пропускается командой самого плеера за доли секунды — даже до кнопки «Пропустить». YouTube и YouTube Music.

Без спонсорских вставок

Таймкоды из открытой базы SponsorBlock. Для каждой категории — пропускать, спрашивать или только отмечать.

Скорость до 4×

Прямо в меню скорости плеера и клавишами Shift+> / Shift+<. Плюс скорость по умолчанию и для каждого канала.

«К главному»

Кнопка в плеере переносит к самому интересному моменту — по метке SponsorBlock или пику «самых пересматриваемых».

Дизлайки вернулись

Число дизлайков на кнопке под видео — по данным Return YouTube Dislike.

Как в Premium

Качество по умолчанию, без «Продолжить просмотр?», без автовоспроизведения и — по желанию — логотип Premium.

Без отвлекающего

Скрывайте ленту на главной, рекомендации, комментарии, карточки поверх видео и Shorts — каждое отдельно.

Shorts в обычном плеере

С перемоткой, скоростью и всеми функциями UltraTube вместо вертикальной ленты.

Netflix

Пропуск заставки и «Ранее в сериале», по желанию — сразу следующая серия.

Приватно

Никакой аналитики и своих серверов. Настройки и статистика хранятся в браузере. Сегменты SponsorBlock запрашиваются по префиксу хэша — сервер не узнаёт, какое видео вы смотрите. Дизлайки — только ID открытого видео, и это можно выключить.
