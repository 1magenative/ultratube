# План развития UltraTube

Идеи, которые обсуждали, но ещё не сделали. Порядок — примерный приоритет.

## Режим «Сеть»: обход замедления YouTube только в браузере

**Проблема.** В РФ YouTube замедляют через DPI провайдера. Инструменты вроде [zapret](https://github.com/bol-van/zapret) и GoodbyeDPI обходят это на уровне сетевых пакетов (дробят TLS ClientHello, шлют фейковые пакеты с малым TTL). Расширению Chrome доступ к пакетам закрыт — «zapret внутри расширения» невозможен даже теоретически. Расширения-«ускорители» почти всегда гонят трафик через свои прокси-серверы: они видят, что вы смотрите, а серверы кто-то оплачивает.

**Что можно честно сделать** — направлять через прокси *только домены YouTube* (`youtube.com`, `googlevideo.com`, `ytimg.com`, `ggpht.com`), а остальной трафик оставлять прямым:

1. **Локальный ByeDPI** (рекомендуемый режим). [ByeDPI](https://github.com/hufrea/byedpi) — та же идея, что у zapret, но в виде локального SOCKS5-прокси (`127.0.0.1:1080`). Трафик никуда не уходит с компьютера, десинхронизация происходит локально. Похожий вариант — [SpoofDPI](https://github.com/xvzc/SpoofDPI) (HTTP-прокси).
2. **Свой прокси** (например, свой VPS): поле `хост:порт`.

**Как устроить:**
- разрешение `proxy`, PAC-скрипт через `chrome.proxy.settings` — только для доменов YouTube;
- откат на прямое соединение, если прокси не отвечает: `SOCKS5 127.0.0.1:1080; DIRECT`;
- вкладка «Сеть» в попапе: выключатель, режим, адрес, статус «прокси отвечает / нет» (проверка запросом к `ytimg.com`);
- ограничения Chrome: у SOCKS5 нет авторизации; для HTTP-прокси с паролем нужно `webRequestAuthProvider`;
- по умолчанию выключено, разрешение `proxy` объяснить в README и на странице приветствия (Chrome покажет предупреждение при обновлении);
- своих серверов не держим: это деньги, ответственность за чужой трафик и юридические риски.

## Другие идеи

- **Белый список каналов** — не пропускать вставки и рекламу у авторов, которых хочется поддержать.
- **Режим «Без звука» для вставок** — вместо пропуска (у SponsorBlock есть такой тип сегментов), удобно для «Не музыка».
- **Усилитель громкости** до 300% через Web Audio для тихих роликов.
- **Скриншот кадра** — кнопка в плеере, сохраняет PNG.
- **Повтор фрагмента (A–B)** — для музыки и уроков.
- **Экономия в фоне** — минимальное качество, пока вкладка скрыта.
- **DeArrow** — нормальные заголовки и превью вместо кликбейта (данные от автора SponsorBlock).
- **Отправка своих сегментов в SponsorBlock.**
- **Экспорт и импорт настроек** в файл.
- **Порт на Firefox** (Manifest V3 там тоже есть).
